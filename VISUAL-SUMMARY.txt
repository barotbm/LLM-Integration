                         ✨ KEY FEATURES

═══════════════════════════════════════════════════════════════════════

✅ Token Usage Tracking
   └─ Know exactly how many tokens each extraction uses
   └─ For billing and efficiency analysis

✅ Response Time Measurement
   └─ Network latency (RequestDurationMs)
   └─ API processing time (ProcessingDurationMs)
   └─ Total time (TotalDurationMs)

✅ Automatic Cost Calculation
   └─ Based on real token usage
   └─ Pricing: $2.50/$10.00 per 1M (input/output)
   └─ USD with 6-decimal precision

✅ Request Tracing
   └─ RequestId for OpenAI support
   └─ Timestamp for correlation
   └─ HTTP status for diagnostics

✅ Error Diagnostics
   └─ Error messages captured
   └─ Success/failure flag
   └─ Metrics available even on failure

✅ Backward Compatible
   └─ Old code still works via extension methods
   └─ Optional opt-in for new metrics
   └─ No breaking changes

                         💻 USAGE EXAMPLES

═══════════════════════════════════════════════════════════════════════

OPTION 1: Simple (No Metrics)
────────────────────────────
var invoice = await service.ExtractInvoiceSimpleAsync(text);
Console.WriteLine(invoice?.VendorName);

OPTION 2: Full (With Metrics)
─────────────────────────────
var result = await service.ExtractInvoiceAsync(text);
if (result.Success) {
    Console.WriteLine($"Vendor: {result.Data!.VendorName}");
    Console.WriteLine($"Tokens: {result.Metrics.TotalTokens}");
    Console.WriteLine($"Cost: ${result.Metrics.EstimatedCostUsd:F6}");
    Console.WriteLine($"Time: {result.Metrics.TotalDurationMs}ms");
}

OPTION 3: Batch Processing
──────────────────────────
decimal totalCost = results
    .Sum(r => r.Metrics.EstimatedCostUsd);
int totalTokens = results
    .Sum(r => r.Metrics.TotalTokens);
int successCount = results
    .Count(r => r.Success);

Console.WriteLine($"Cost: ${totalCost:F6}");
Console.WriteLine($"Tokens: {totalTokens:N0}");
Console.WriteLine($"Success: {successCount}/{results.Count}");
